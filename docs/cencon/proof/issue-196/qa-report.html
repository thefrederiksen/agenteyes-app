#FindingSeverity
F1scripts/new-release.ps1:51 throws "... (is it X.Y.Z, or already $Version?). Nothing was changed.". PowerShell parses $Version? as a variable named Version?, which is empty. The message actually printed: (is it X.Y.Z, or already ). Nothing was changed. The refusal itself is correct (nothing written, no tag). The fix is ${Version}?.cosmetic
F2The script's -replace runs on the raw file, so a <Version> inside an XML comment would also be rewritten. Counting and validation correctly ignore comments. No project has one today.latent
F3The script searches TRACKED files (git ls-files). The test walks the file system, which also covers untracked files. The test is the broader of the two, which is the right way round. An untracked project would not be in the release commit anyway.info
F4Pre-existing, outside this issue: the About text says "for Linux" on every platform (the developer noted this). build-app.sh:61 rejects a -rc.N version, so the macOS bundle cannot be built for a pre-release. It fails loudly, not silently.out of scope
