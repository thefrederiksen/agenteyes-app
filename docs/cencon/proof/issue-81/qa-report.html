Codex review blockers - independently confirmed fixed

  • Blocking 1 (stats I/O broke recovery / duplicate capture): all day saves on the restart path go through SaveDay, which catches IOException/UnauthorizedAccessException and logs; the recovery stamp (NoteRecovery) is outside the start try; StartRecorder throws if _recorder != null, so a second capture can never overwrite a live one. Regressions Tick_StatsFileLockedWhenACaptureFails_TheCaptureStillRestarts, Tick_StatsFileLockedWhenTheRestartRecovers_NoSecondCaptureIsStarted.
  • Blocking 2 (dead replacement marked recovered): StartRecorder checks HasExited right after Start, disposes the failing recorder and throws, so the engine stays Retrying; RecoveredUtc is stamped only when the new capture opens a piece of its own (by filename, not timestamp). Regressions Tick_ReplacementIsAlreadyFailingWhenItStarts_StaysRetryingAndIsNotRecovered, Tick_ReplacementOpensAPiece_OnlyThenIsTheRestartRecovered.
  • Follow-ups in 9238e69 are docs only (stall 2 worded as hypothesis; live check judged per outage).
