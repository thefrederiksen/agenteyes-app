Diagnosis from the code: the test releases its wedged publisher (stalled.Set()) as its LAST statement, so the publisher thread can still be inside a write of screen.jpg when xunit runs the class Dispose(), which deletes the directory recursively (:35). That teardown catches only IOException (:36); an open file makes Windows throw UnauthorizedAccessException, which escapes and fails the test. PreviewTapTests.cs is untouched by PR #95 (git diff main...HEAD --stat on it is empty; last changed in #75/#33), the class passes 24/24 alone in five runs, and the race showed once in three full runs here and once in the developer's runs (their unnamed one-off, now named). Filed as issue #96 so it is not lost. It does not change the #94 verdict: the criterion is the change's gate, and the change's gate run (run 1) and run 3 are green and named.
