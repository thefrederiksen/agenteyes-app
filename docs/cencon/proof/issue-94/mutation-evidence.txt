Review fix pass (PR #95 self-review findings) - M4: the working-directory regression test
-----------------------------------------------------------------------------------------------

The review found that the first version's `Path.GetDirectoryName(exePath) ?? _layout.AppDir` could never
fall back: for a bare "AgentEyesApp.exe", GetDirectoryName returns "" (not null), and CreateProcessW
rejects "" as lpCurrentDirectory. The fix resolves the exe with Path.GetFullPath first; the regression
test Launch_BareExeNameInTheCurrentDirectory_StartsIt starts "cmd.exe" by bare name with the process's
current directory set to System32 (safe: the class now runs in a non-parallel collection).
