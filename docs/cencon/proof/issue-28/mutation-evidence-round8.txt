NOTE ON M6 - A CHECK THAT COULD NOT FAIL, FOUND AND CLOSED IN THIS ROUND
=======================================================================

On its first pass M6 (recording the quit as DELIVERED even when the write to ffmpeg's stdin threw)
fired NO test: 947 passed with the delivery clause defeated. The reason is that the existing
round-4 test for an undelivered quit pairs it with exit code -5, so the ENUMERATED EXIT-CODE SET
alone is enough to refuse the clean quit and the delivery half of the rule is never the thing under
test.

That is an absence-shaped check, and it was closed with a presence-shaped one:
Stop_WhenTheQuitCouldNotBeDeliveredAndTheProcessExitedZero_IsStillNotACleanQuit drives an
undelivered quit whose process then exits with 0 - a code that WOULD be accepted - so the only thing
standing between that take and a false "clean-quit / yes" is the fact that the "q" never arrived.
M6 now fires on it.
