5. WHAT THIS PROBE CANNOT SEE
-----------------------------------------------------------------------------------

* It drives the recorder through ICameraProcess, so it establishes what the recorder does
  with what the OS tells it - not what a real ffmpeg on a real dshow device will tell it.
  AC3, AC9, AC10 and AC17 were therefore ALSO run against the real eMeet C960 webcam; see
  the QA report.
* It cannot see a termination issued by something outside AgentEyes (Task Manager, the OS).
  The design answers that case with an ABSENT kind, which is what an unwatched ending is
  worth, and the probe asserts that absence rather than a claim.
* AC1's "a machine with no camera reports []" and AC2's "(none found)" cannot be RUN on
  this machine (it has two cameras). The enumerator half is run
  (Ac1_AnAudioOnlyDshowListing_EnumeratesNoCameras: cameras=0 mics=1, so the parser is
  proved to have matched something in that same listing); the surfaces that read it are
  code-verified only (RestServer.Devices has no fallback; Commands.cs:71 prints
  "(none found)" when Count is 0).
