Every check added or rewritten in this round, RUN AGAINST THE UNFIXED (round-3) CODE FIRST.

The Review Gate's round-3 REJECT called out that one committed test could not fail
(CameraFailurePathTests.Stop_AfterAFailedTermination_...): it set KillEndsIt = false and
then asserted only that a second kill had been ATTEMPTED and that the wrapper had been
disposed - both true whether or not ffmpeg died. So this round every new and every
rewritten check was run against a mutation that restores the exact round-3 behaviour, and
the failing output is reproduced verbatim below. A check that did not fire against its
mutation would be treated as a defect, not as weak coverage.

HOW TO REPRODUCE. Each mutation is a one- or two-line edit named in its section. Apply it,
then run:

    dotnet test AgentEyes.sln -c Release
        -p:UseArtifactsOutput=true -p:ArtifactsPath=<a scratch dir>
        --filter "FullyQualifiedName~CameraFailurePathTests"

The isolated ArtifactsPath is not cosmetic: the running tray app (AgentEyesApp.exe) holds a
write lock on src\AgentEyes.App\bin\x64\Release\...\agenteyes.dll, so a normal-path build
fails MSB3027 and a stale bin\ can hand back a green that tested code nobody built. The
Review Gate built from isolated artifacts for the same reason.
