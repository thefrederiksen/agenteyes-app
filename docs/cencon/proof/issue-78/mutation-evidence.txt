Each mutation below was applied to the committed branch, the solution was rebuilt
(dotnet build AgentEyes.sln -c Release), ONLY the TestIsolationTests class was run
(dotnet test ... --filter FullyQualifiedName~TestIsolationTests), and the file was reverted.

then write into the REAL %LOCALAPPDATA%\AgentEyes of this machine, where the owner's app is live.

guard is instead shown to fire through the pid mutation (M2) and the ordering mutation (M5).
