7. WHAT A MIC READING THROUGH /status NEEDS, AND WHY IT IS 0 HERE
-----------------------------------------------------------------
The AvfStream fix is what lets the level meter OPEN at all, and it does now open. It still reads
nothing in a SERVICE process on this machine:

  (installed launchd service, mode=audio, the service owns the samples)
  $ curl -X POST .../record/start -d '{"mode":"audio","screen":1,"source":"mic","mic":"Yealink"}'
  { "State": "recording", "Mode": "audio", "Source": "mic", "MicLevel": 0, ... }
  10 x /status over 6.6 s while sound played:  MicLevel=0  Level=0 every time
  $ curl -X POST .../record/stop -d '{}'
  { "DurationSeconds": 6.62, "File": ".../2026-11-12_104903_audio/audio.wav" }
  $ ls -l ~/Movies/AgentEyes/2026-11-12_104903_audio/audio.wav     ->  44 bytes (header only)
  log: [AvfStream] Start mic: ... -f avfoundation -i :1 ...        (the corrected command line)
       [WARN] [AvfStream] Stop mic: ffmpeg did not finish within 5s - killing it
       [INFO] [AudioCapture] Stop: wrote 0 bytes of PCM

The same build, same device, same command line, run as a CHILD OF THE TERMINAL, writes 488448
bytes of real audio (section 2). The difference is the microphone privacy grant, not the argument
list. Proven by running ffmpeg itself orphaned from the shell, with nothing of AgentEyes involved:

  $ nohup sh -c 'sleep 10; ffmpeg -f avfoundation -i ":1" -t 3 -y orphan_mic.wav' &
  (the shell exits; the capture runs with launchd as its parent)
  ... 2 minutes later: no orphan_mic.wav at all, empty stderr, and the ffmpeg process still alive
      and hung on a -t 3 capture. Killed with SIGKILL.

So on this Mac a detached process (the launchd agent, or anything orphaned) gets a microphone that
never delivers a sample, while a terminal child gets real audio. That is a macOS Microphone
permission for the service, and like Screen Recording only the owner can grant it. It is NOT
something this issue's code can fix, and it is why the /status MicLevel half of AC4 is also
recorded as blocked rather than passed.
