The test passed in the other 20 runs. This is a pre-existing test-fixture race in another area; the issue's criterion 2 is about CameraPreviewTests, which passed in all 21 runs, and runs 2-21 are 20 consecutive fully green runs. Recommend a separate [Tests] issue for the PreviewTapTests fixture.
